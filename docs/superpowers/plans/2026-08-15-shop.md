# 상점 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 전투로 쌓인 재화를 쓰는 상점을 만들고, 상점 자리를 차지하고 있던 전투 진입점을 새 "전투터" 건물로 옮긴다.

**Architecture:** 데이터(`EggData` / `ShopStockDatabase`) → 코어(`ShopService`, 순수 C#) →
표시(`ShopPanel`, `PanelLabels`) → 씬 생성(`GameBootstrap`) → 검사(`SceneIntegrityCheck`) 순서로 쌓는다.
알은 장착 아이템(`ItemData`)과 **별개 계통**이라 창고 코드를 한 줄도 건드리지 않는다.
인벤토리가 문자열 id 기반이라 세이브는 v3 그대로다.

**Tech Stack:** Unity 6000.2.8f1 (2D), C#, NUnit (Unity Test Framework), uGUI

**Spec:** `docs/superpowers/specs/2026-08-15-shop-design.md`

## Global Constraints

이 프로젝트에는 **종료 코드 0 이 성공을 뜻하지 않는** 함정이 여러 개 있다. 모든 태스크에 적용된다.

- **씬을 손으로 편집하지 않는다.** 씬은 `GameBootstrap.BuildAll()` 이 전량 생성한다.
- **배치모드 실행은 Unity 에디터가 닫혀 있어야 한다** (프로젝트 잠금).
- **UI 행·슬롯을 런타임에 생성하지 않는다.** 개수는 씬 생성 시점에 고정된다 (함정 3.1).
- **uGUI persistent listener 는 `int` 인자만 쓴다.** `AddObjectPersistentListener` 는 빈 항목을 남긴다 (함정 3.6).
- **`NewScene` 은 그 이전에 얻은 에셋 참조를 죽인다.** 개수가 0 이면 `Debug.LogError` 로 크게 실패시킨다 (함정 3.9/3.10).
- **패널은 `Canvas` 하위에 두고, 배선이 끝난 뒤 닫아서 저장한다** (함정 3.7/3.8).
- 새 에셋은 전부 `LoadOrCreate` 로 만든다 — `LoadOrSeed`(seed-only) 가 아니다 (함정 3.11).
- 알 id 는 **`egg_` 로 시작**한다. 아이템 id 와 같은 인벤토리 키 공간을 쓴다.
- 세이브 버전은 **v3 그대로**. `SaveData.CurrentVersion` 을 건드리지 않는다.

`Assets/Scripts/Runtime/Data/EggDatabase.cs`:

```csharp
using System.Collections.Generic;
using UnityEngine;

namespace FarmCreature.Data
{
    /// <summary>알 목록. 상점이 id 로 표시 이름을 찾을 때 쓴다.</summary>
    [CreateAssetMenu(fileName = "EggDatabase", menuName = "FarmCreature/Egg Database")]
    public class EggDatabase : ScriptableObject
    {
        public List<EggData> eggs = new List<EggData>();

        public EggData Find(string eggId)
        {
            if (string.IsNullOrEmpty(eggId) || eggs == null)
            {
                return null;
            }

            for (int i = 0; i < eggs.Count; i++)
            {
                if (eggs[i] != null && eggs[i].eggId == eggId)
                {
                    return eggs[i];
                }
            }

            return null;
        }
    }
}
```

`Assets/Scripts/Runtime/Data/ShopStockDatabase.cs`:

```csharp
using System.Collections.Generic;
using UnityEngine;

namespace FarmCreature.Data
{
    /// <summary>파는 물건이 어느 계통인가. 표시 이름을 어디서 찾을지만 정한다 (설계 3.2).</summary>
    public enum ShopEntryKind
    {
        Equipment = 0,
        Egg = 1
    }

    /// <summary>판매 목록 한 줄.</summary>
    [System.Serializable]
    public class ShopEntry
    {
        public ShopEntryKind kind = ShopEntryKind.Equipment;

        [Tooltip("장비면 ItemData.itemId, 알이면 EggData.eggId. 인벤토리에 이 문자열이 그대로 담긴다.")]
        public string targetId;

        [Tooltip("판매가. 0 이하는 데이터 실수로 본다 — ShopService 가 거부한다.")]
        public int price = 1;
    }

    /// <summary>
    /// 상점 판매 목록. <b>상점 패널의 행 개수가 여기서 나온다</b> —
    /// 항목을 늘리면 <c>GameBootstrap.BuildAll</c> 을 다시 돌려야 한다 (함정 3.1).
    /// </summary>
    [CreateAssetMenu(fileName = "ShopStockDatabase", menuName = "FarmCreature/Shop Stock Database")]
    public class ShopStockDatabase : ScriptableObject
    {
        public List<ShopEntry> entries = new List<ShopEntry>();

        public int Count
        {
            get { return entries != null ? entries.Count : 0; }
        }

        /// <summary>범위를 벗어나면 null. 버튼이 인덱스를 들고 있어 방어가 필요하다 (함정 3.6).</summary>
        public ShopEntry Get(int index)
        {
            if (entries == null || index < 0 || index >= entries.Count)
            {
                return null;
            }

            return entries[index];
        }
    }
}
```

```csharp
using FarmCreature.Data;

namespace FarmCreature.Core
{
    /// <summary>
    /// 상점 구매 규칙. <b>순수 C# 이다</b> — 표시 이름을 인자로 받아서 데이터베이스를 뒤지지 않는다.
    /// 그래야 EditMode 테스트가 에셋 없이 돈다.
    ///
    /// 차감이 먼저이고 지급이 나중이다. <see cref="GameState.TrySpendGold"/> 는 모자라면
    /// 아무것도 바꾸지 않으므로 <b>절반만 적용된 상태가 생기지 않는다</b> (설계 4절).
    /// </summary>
    public static class ShopService
    {
        public static ActionResult TryBuy(GameState state, ShopEntry entry, string displayName)
        {
            if (state == null || state.Inventory == null || entry == null
                || string.IsNullOrEmpty(entry.targetId))
            {
                return ActionResult.Fail("살 수 없는 물건이다.");
            }

            // 0 이하는 "무료 증정"이 아니라 데이터를 잘못 적었다는 뜻이다. 조용히 넘기지 않는다.
            if (entry.price <= 0)
            {
                return ActionResult.Fail("가격이 정해지지 않은 물건이다.");
            }

            if (!state.TrySpendGold(entry.price))
            {
                return ActionResult.Fail("재화가 모자란다. (" + entry.price + " 필요)");
            }

            state.Inventory.Add(entry.targetId, 1);

            string name = string.IsNullOrEmpty(displayName) ? entry.targetId : displayName;
            return ActionResult.Ok(name + "을(를) 샀다. (−" + entry.price + ")");
        }
    }
}
```

```csharp
using FarmCreature.Core;
using FarmCreature.Data;
using UnityEngine;
using UnityEngine.UI;

namespace FarmCreature.Presentation
{
    /// <summary>
    /// 상점 — 장비와 알을 산다. 행은 <see cref="ShopStockDatabase"/> 인덱스와 1:1 이고
    /// 개수가 씬 생성 시점에 고정된다 (함정 3.1). 구매 버튼은 <b>int 인자 persistent listener</b>
    /// 로 그 인덱스를 넘긴다 (함정 3.6).
    ///
    /// 규칙은 <see cref="ShopService"/> 한 곳에만 있다 — 이 패널은 표시와 배선만 한다.
    /// </summary>
    public class ShopPanel : GamePanel
    {
        public Text titleText;

        [Tooltip("ShopStockDatabase 인덱스 순서와 같아야 한다. GameBootstrap 이 채운다.")]
        public Text[] rowTexts;

        [Tooltip("판매 목록. 행 개수가 여기서 나온다. GameBootstrap 이 채운다.")]
        public ShopStockDatabase stockDatabase;

        [Tooltip("알 이름을 id 로 찾을 때 쓴다. GameBootstrap 이 채운다.")]
        public EggDatabase eggDatabase;

        [Tooltip("로그와 전체 갱신을 맡길 조율자. GameBootstrap 이 채운다.")]
        public CareManager careManager;

        /// <summary>uGUI 버튼이 재고 인덱스를 넘긴다.</summary>
        public void Buy(int entryIndex)
        {
            var entry = stockDatabase != null ? stockDatabase.Get(entryIndex) : null;
            if (entry == null)
            {
                Log("그 물건은 팔지 않는다.");
                return;
            }

            var result = ShopService.TryBuy(state, entry, DisplayNameOf(entry));

            // 성공이든 실패든 다시 그린다 — 재화 표시가 HUD 와 패널 양쪽에 있다.
            if (careManager != null)
            {
                careManager.RefreshAll();
            }
            else
            {
                Refresh();
            }

            Log(result.Message);
        }

        public override void Refresh()
        {
            if (titleText != null)
            {
                titleText.text = PanelLabels.ShopTitle(state);
            }

            if (rowTexts == null)
            {
                return;
            }

            int count = stockDatabase != null ? stockDatabase.Count : 0;
            var inventory = Inventory;

            for (int i = 0; i < rowTexts.Length; i++)
            {
                if (rowTexts[i] == null)
                {
                    continue;
                }

                var entry = i < count ? stockDatabase.Get(i) : null;
                if (entry == null)
                {
                    rowTexts[i].text = string.Empty;
                    continue;
                }

                int owned = inventory != null ? inventory.GetCount(entry.targetId) : 0;

                rowTexts[i].text = entry.kind == ShopEntryKind.Egg
                    ? PanelLabels.ShopRow(FindEgg(entry.targetId), entry.price, owned)
                    : PanelLabels.ShopRow(FindItem(entry.targetId), entry.price, owned);
            }
        }

        private string DisplayNameOf(ShopEntry entry)
        {
            if (entry.kind == ShopEntryKind.Egg)
            {
                var egg = FindEgg(entry.targetId);
                return egg != null ? egg.displayName : entry.targetId;
            }

            var item = FindItem(entry.targetId);
            return item != null ? item.displayName : entry.targetId;
        }

        private EggData FindEgg(string eggId)
        {
            return eggDatabase != null ? eggDatabase.Find(eggId) : null;
        }

        private ItemData FindItem(string itemId)
        {
            return itemDatabase != null ? itemDatabase.Find(itemId) : null;
        }

        private void Log(string message)
        {
            if (careManager != null)
            {
                careManager.SetLog(message);
            }
        }
    }
}
```
